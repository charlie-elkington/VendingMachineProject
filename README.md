# VendingMachineProject

A vending machine built in python that utilises functions, iteration and selection.  The vending machine accepts and rejects coins, allows you to choose an item from a list, displays your change (if there is any), and refunds you if you haven't entered enough money.

## Prerequisites
- Install Python
- Git (if cloning the repository)
- Run "pip install colorama" in the terminal
